# Assets — provenance and licenses

## Sample photos

- `app/samples/boulevard.jpg` and `app/samples/pier.jpg` are the two
  sample photos shipped with the gta6-cover-art-01 kit. They were made
  with an image model for make.fun and are free to use. No real person
  is depicted; no consent is needed. The app's default cover crops them
  differently per panel (a detail crop is a crop, not a new photo).

## Fonts

- `app/fonts/Anton-Regular.ttf` — Anton, copyright 2020 The Anton
  Project Authors, SIL Open Font License 1.1.
- `app/fonts/Pacifico-Regular.ttf` — Pacifico, copyright 2018 The
  Pacifico Project Authors, SIL Open Font License 1.1.
- `app/fonts/OFL.txt` — the full SIL Open Font License 1.1 text.

Both fonts were downloaded from the official Google Fonts repository
(github.com/google/fonts, `ofl/anton/` and `ofl/pacifico/`). No game
font is used anywhere in this entry.

## Code

- `vendor/makefun-app.ts` is the kit's library, copied unchanged.
- Every other source file in `app/src/`, plus `main.ts`, was written
  for this entry in the recorded build session.
